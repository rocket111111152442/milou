Générateur de démos

Écrivez votre message une fois, importez votre fichier Excel de prospects : chaque paysagiste obtient son site et son message prêts à copier-coller.

ÉTAPE 1

Votre message

Il est enregistré dans ce navigateur. Cliquez sur une variable pour l'insérer : elle sera remplacée pour chaque prospect.

ÉTAPE 2

Vos prospects

Fichier .xlsx, .xls ou .csv, une ligne par entreprise. Colonnes reconnues : nom (obligatoire), ville, téléphone, note, avis, code postal, adresse. Les noms de colonnes peuvent varier (« Entreprise », « Tel », « Nombre d'avis »…).

Glissez votre fichier Excel ici ou cliquez pour le choisir

Ajouter un prospect à la main
ÉTAPE 3

Copier-coller

« Copier le message » copie le texte complet avec le lien. Cochez « Envoyé » au fur et à mesure : la liste est gardée dans ce navigateur.
